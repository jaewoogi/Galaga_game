# GALAGA · Retro Squadron (Fan Game)

순수 웹 기반 갤러그 팬 게임입니다. ROM/외부 에셋 없이 프로시저럴 픽셀 스프라이트 + 합성 사운드만 사용합니다.

## 주요 개선 (이번 버전)

- **터치 조이스틱 초고감도**: 작은 움직임에도 빠르게 좌·우 최대 속도에 도달
- **기체 납치 연출**: 보스가 포획할 때 우주선이 위로 빨려 올라가는 애니메이션 + 전용 효과음
- **CHALLENGING STAGE (easy left-right exit)** (기존 보너스 스테이지 3,7,11…): 적들이 아래로 내려오지 않고 **좌우로 빠르게 빠져나감**. 높은 위치에서 천천히 지나가 쉽게 맞출 수 있는 쉬운 챌린지 스테이지
- **갤러그 감성 효과음**: 포획, 듀얼 파이터, 스테이지 클리어, 위험 스테이지 진입 등 시퀀스 사운드 강화
- **그래픽 강화**: 더 풍부한 별 배경, 탄환 트레일, 파티클, 캡처 시 화면 플래시

## 조작

| 키 / 터치 | 동작 |
|-----------|------|
| ← → / A D / 스틱 | 좌우 이동 |
| SPACE / FIRE 버튼 | 발사 (길게 = 연사) |
| P / ESC | 일시정지 |
| M | 사운드 토글 |
| TURBO | 탄환 속도 증가 (모바일) |

## 배포 (GitHub Pages)

2. Settings → Pages → Source: Deploy from a branch → main / root
3. 잠시 후 `https://<username>.github.io/<repo>/` 에서 플레이
